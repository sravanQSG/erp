# demo-erp Web

React 19 + Vite SPA for the demo-erp platform. Part of the
[demo-erp](../../README.md) pnpm monorepo.

## Stack

- **React 19** + **TypeScript** (strict mode), **Vite**
- **TanStack Router** — file-based routing (`src/routes/`), code generates
  `src/routeTree.gen.ts` (gitignored, regenerated by `vite dev`/`vite build`)
- **TanStack Query** — server state, caching, and the auto-refresh-on-401
  retry flow (see `src/lib/api-client.ts`)
- **TanStack Table** (`/legacy` subpath API — see note below) — the
  `DataTable` component backing every list page
- **React Hook Form + Zod** — form state and schema validation
- **shadcn/ui-style components + Tailwind v4** — `src/components/ui/`
- **`@demo-erp/shared-types`** — JWT payload shape, permission keys, and
  DTO types shared with the backend (`apps/api`)

## Running

From the monorepo root:

```bash
pnpm install
pnpm dev:web      # http://localhost:5173
```

Requires the backend running too (`pnpm dev:api`, defaults to
`http://localhost:3000`) — see [apps/api/README.md](../api/README.md). Set
`VITE_API_URL` if the API isn't on the default URL.

Also make sure the backend's `CORS_ORIGIN` (`apps/api/.env`) matches this
app's dev origin (`http://localhost:5173`).

## Auth model

The JWT access/refresh token pair is stored in `localStorage`
(`src/lib/auth.ts`). The access token is decoded **client-side only for UI
gating** (showing/hiding nav items by permission) — it is never trusted as
a security boundary; the backend independently re-checks every request.
Navigating directly to a nav-hidden route is correctly blocked server-side
with a 403, surfaced via the `QueryError` component
(`src/components/query-error.tsx`) rather than an infinite loading state.

## Note on `@tanstack/react-table`

This project pins a very recent major version (v9) that shipped a complete
API rewrite from the commonly-documented v8 API. It still ships an official
`/legacy` subpath (`@tanstack/react-table/legacy`) exposing the familiar
`useReactTable`/`ColumnDef`/`getCoreRowModel` API, which is what
`src/components/data-table.tsx` uses. If a future upgrade removes that
subpath, `data-table.tsx` will need a v9-native rewrite.
